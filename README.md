# Sadoun Barbershop

Enkel statisk nettside (HTML/CSS/JS, ingen bygging) for Sadoun Barbershop, Torggata 15, Skien.

- Åpne `index.html` direkte, eller kjør `python3 -m http.server` og gå til http://localhost:8000
- Norsk som standard, bryter for engelsk øverst til høyre (`script.js`)
- Skrifter ligger lokalt i `fonts/`

## Må byttes ut med ekte info
- Priser: `index.html`, seksjonen `#priser` (eksempelpriser)
- Åpningstider: `index.html`, seksjonen `#apent` (eksempeltider)
- Bilder/logo: ikke lagt inn ennå – siden bruker en tegnet barberstolpe/skilt
