# Sadoun Barbershop

Enkel statisk nettside (HTML/CSS/JS, ingen bygging) for Sadoun Barbershop, Torggata 15, Skien.

- Åpne `index.html` direkte, eller kjør `python3 -m http.server` og gå til http://localhost:8000
- Norsk som standard, bryter for engelsk øverst til høyre (`script.js`)
- Skrifter ligger lokalt i `fonts/`
- Designsystemet er beskrevet i `DESIGN.md`; produktfakta i `PRODUCT.md`

## Må byttes ut med ekte info (står tydelig merket på siden)
- Priser: `index.html`, seksjonen `#priser`. Fjern også «Eksempelpriser»-merknaden (`prices.note` i `script.js`)
- Åpningstider: `index.html`, `#apent`. Fjern «eksempeltider» (`hours.flag` i `script.js`)
- Bilder og logo: ikke lagt inn ennå. Siden bruker en tegnet barberstolpe på et lite skilt (bare på brede skjermer)
